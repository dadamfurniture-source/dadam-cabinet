# 휴렉 (HULEC) — `brands/hulec.py`

싱크대에 붙여 쓰는 '설치형' 음식물처리기. 종류 `food_disposer` (하부장 가전, 2026-11-03).

```bash
python -I collect.py --brands hulec --sample 3 --out sample_hulec
python -I collect.py --brands hulec --out out_hulec      # 요청 5개 (robots 1 + 소개 2 + 상품 2)
```

## 출처

| 설치 장소 | 소개 페이지 글 `설치장소 : 싱크대 및 수납 스페이스` (싱크대가 없으면 뺀다) | — |
| 모델 코드 · 외경 | 소개 페이지 '설명서 다운로드' PDF (`houssen02.cafe24.com/hulec/manual_gini.pdf` · `manual_windi.pdf`) 의 '제품규격' 표. PDF 에 글자 층이 없어 쪽을 그림으로 만들어 눈으로 읽었다 → 파일 안 `MANUAL` | `이미지판독` · `매뉴얼` (미검증) |
| 사진 | 상품 페이지(`detail.html?product_no=257 · 319`) 대표 사진 | — |

- robots.txt: `www.hulec.co.kr` 은 카페24 기본(`/exec/front/` · `/member/` · `/myshop/` · `/skin-*/` · 게시판 쪽 넘김 금지) — 소개 · 상품 페이지만 부른다. `houssen02.cafe24.com` 은 `User-agent: Yeti` 무리만 있어 우리 UA 를 막지 않는다. 둘 다 받기 전에 확인했다.
- 설명서 PDF 2개는 robots 확인 뒤 한 번씩 받아 읽었다 (2026-11-03). 수집기는 PDF 를 다시 받지 않고, 소개 페이지가 같은 설명서 주소를 걸고 있는지만 본다. 주소가 바뀌면 치수를 넣지 않는다 (`치수확인필요` → SQL 에서 빠진다).

## 정확도가 떨어지는 행 · 사장님 확인 필요

- **둘 다 `이미지판독`** — 설명서 표가 그림이다. 원문 칸 이름은 그대로 옮겼다 (지니 `H × W × D`, 윈디 `W × D × H`).
- 지니 상품 페이지에는 모델 코드가 없다. 코드 HB-3100H 는 그 페이지가 거는 설명서 표 값이다. 렌탈 비교 사이트들은 옛 코드 HB-2000HM · 프리미엄 HB-5000HM 을 쓴다 (값은 쓰지 않았다).
- 지니는 2차 처리기와 디스포저 두 덩어리다. 외경 칸은 하부장 바닥에 놓는 2차 처리기다 — 하부장 안 높이는 디스포저(285) + 배관도 함께 봐야 한다 (설치 공간 표는 설명서에 없다).
- 윈디 340.5 · 406.5 는 장 안 치수를 줄이지 않게 올려 341 · 407 로 넣었다.

## 못 모은 것

- 지니 설치형 프리미엄 블랙 (주문제작, 최소 200개) `product_no=307` — 사양 · 코드가 없다 (상단 그림 이름만 HB5000).
