- robots.txt: `www.cuchenmall.co.kr` 은 `/a/` · `/_manage/` 만 막는다 (게시판 · 상품 · 목록 허용). `cuchencdn.wisacdn.com/robots.txt` 는 404.
- 매뉴얼 '제품크기 (길이 X 폭 X 높이)' 의 **길이 = 깊이(D), 폭 = 가로(W)**. 쿠첸 설명서는 이 뜻으로 일관된다 — NEW 121 6인용 설명서 `267 X 376 X 264`(길이 X 폭) 는 페이지 `375(W)*269(D)` 와, 121 플러스 10인용 `397×301×294` 는 블라썸화이트 페이지 `301(W)*397(D)` 와, 전기압력밥솥 10인용 `409.5 × 300` 은 페이지 `294.5(W)*409.5(D)` 와 같은 뜻. 몇몇 설명서는 `(폭 X 길이 X 높이)` 로 적었다 (VPRS064 · VPRS104 · 전자레인지) — 칸 이름대로 읽는다.
- 쿡탑 설명서 '크기 (길이 x 폭 x 높이) 595 x 520 x 55' 는 길이 = 가로(W) (설치 쪽 '(W)595 X (D)520 X (H)55' 와 같다).
- 글꼴 때문에 숫자가 깨져 뽑히는 설명서(CRM-H0640 · CRH-ZWD064 · CRS-WK101/061 · CRT-WS03/TWK03)는 글꼴 코드표(U+F6B1~ · U+5809~ = 0~9)로 풀었고, `220 V~, 60Hz` · 페이지 값과 맞는 것으로 확인했다 (CRM-H0640 은 쪽 그림으로도 확인) → `매뉴얼`.
- 2025~26년 '통합 설명서 Full' (PX_06/10 Full · titan · UPDS · TWK · TWS · LUPDSS · OUPDSW · TWD0610)에는 크기 칸이 아예 없다. 123 듀얼프레셔(PX)만 같은 문서의 12쪽판(5쪽)에 크기가 있는데 숫자 글꼴이 글자로 뽑히지 않아 쪽 그림을 보고 읽었다 → `이미지판독`. PX Full 판을 건 상품도 이 12쪽판 값을 쓴다.
- 설명서 값이 페이지와 ±2 mm 안이면 페이지 값을 그대로 두고 태그를 달지 않는다 (비고에 '사용설명서 n쪽과 같음'). 다르면 설명서 값으로 고치고 `매뉴얼` (눈으로 읽은 것은 `이미지판독`).
- 설명서가 없거나 크기가 없는 밥솥 중 같은 인분 · 같은 세 치수(±2)인데 W · D 만 반대인 행은 설명서로 확인한 행의 방향에 맞추고 `치수순서추정` (값은 그 페이지 값). 그러지 않으면 `flag_permuted` 가 확인된 행까지 `치수순서의심` 으로 묶는다.
- `3.5인용` · `1.5인용` 은 `K.place_count` 가 5 로 읽어 인분 칸을 비운다.
