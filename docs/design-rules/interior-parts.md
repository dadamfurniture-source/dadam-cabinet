# 모듈 속 부재 — 석가 · 선반 · 속서랍

> 2026-10-29 사장님 확정. 정본 코드: `js/detaildesign/bom-interior-rules.js` (배치) · `extractors.js` (자재 · 레일) · `bom-assembly.js` (조립 명세) · `ui-step1.js` (브리지).
> 간편 플래너(dadam-planner-lite)의 **석가 · 서랍(속서랍 · 일반서랍) · 선반** 단추로 사람이 모듈마다 더하고 뺀다.

## 1. 표시

| 자리 | 값 |
|---|---|
| 플래너 구조 | `s.interior = { mids: [석가 중심 y], inner: 속서랍 단수 }` · 선반은 원래 자리 `s.shelves` (중심 y) |
| BOM 모듈 | `mod.interior = { mids: [y], inner }` (브리지가 그대로 싣는다) |

- y 는 몸통 밑면에서 판 **중심**까지 (지판 T 포함 — `planner-engine.js shelvesEvenInner` 와 같다).
- 표시가 있는 모듈은 **사람이 속을 정한 모듈**이다 — 선반 수도 구조(`s.shelves`) 그대로 낸다. 싱크 상부장 선반 2 · 하부장 1 고정을 타지 않는다 (0 이면 없음).
- 표시가 없는 모듈은 예전과 같다. 서랍장 · 오픈장 · 붙박이장 통에는 싣지 않는다 (그 규칙이 속을 정한다).

## 2. 석가 (중간판) — 「몸통과 같은 판 · 칸 균등」

| 항목 | 값 |
|---|---|
| 판 | 몸통 PB T (15) · 고정 (선반 핀 없음) |
| 가로 | 측판 사이 W − 2T |
| 깊이 | 천지판 깊이 — 사쿠리 몸통(상부장 · 단순 품목 상부 · 띄움) D − 18, 하부장 짜임 지판 D |
| 앞 기둥 | 처짐방지목이 있는 폭(상부 700 · 하부 800 이상 — `assembly-rules.js braceQtyOf`)이면 **그 뒤까지** (깊이 − T) — 「석가를 처짐방지목 뒤까지」. 처짐방지목은 지판 ~ 천판 그대로 |
| | 멍장은 ㄱ자 기둥 깊이만큼 (선반과 같은 `blindShelfCut`) |
| 자리 | n 장이면 몸통 안(속서랍 위)을 n + 1 칸으로 고르게 나눈다. 뒤끝 = 천지판 뒤끝 |

## 3. 선반 — 「1장씩, 간격 균등」

- 칸마다 고르게 놓는다. 장수는 칸에 고르게 나누고, 남는 장은 **아래 칸부터**.
- 칸 간격 = 칸 안 높이 ÷ (그 칸 선반 + 1). 최소보다 좁으면 막는다 — 일반 **200** (2026-10-30 사장님 「200 으로 낮추기」 — 기본 선반 수 규칙 `MASTER_RULES.SHELF_SPACE_MIN` 300 과는 따로), 신발장 **150** (`SHELF_SPACE_MIN_SHOE`).
  하부장(몸통 안 678) 선반 2 · 상부장(690) 선반 2 · 석가 1 + 선반 1 이 들어간다.
- 판은 각 품목 선반 규칙 그대로 (사쿠리 D − 34 · 하부장 D − T · 멍장 − 75).

## 4. 속서랍 — 「붙박이장 속서랍 규칙」 (wardrobe.md §7 · `innerDrawerLayout`)

| 항목 | 값 |
|---|---|
| 통 내경 | 몸통 W − 2T |
| 모듈 | W = 통 내경 − 120 (좌우 몰딩 60) · H = 350 × 단수 · D = 몸통 D − 110 (앞 70 + 뒤 40) |
| 놓는 자리 | 몸통 **지판 위** — 차지하는 높이 350 × 단수 + 상판 T. 석가 · 선반은 그 위 칸에 선다 |
| 전면 · 상판 · 몰딩 | 붙박이장 속서랍 그대로 (전면 = 앞선 − 70, 상판 = 통 내경 × (D − 88), 좌우몰딩 60) |
| 레일 | 문주 언더레일 — 모듈 깊이 − 30 이하 최대 규격 (450 넘지 않음), 단수만큼 |
| 처짐방지목 | **속서랍 상판 위부터** 천판(앞 밴드)까지 — 「처짐방지목을 속서랍 위부터」. 서랍이 앞 가운데 목대에 걸리지 않는다 |

막는 것 (배치 `errors`): 레일이 여유 30 으로 들어가지 않는 깊이 (상부장 295 → 모듈 185), 전면 뒤에 가장 작은 박스도 안 들어가는 높이, 몸통 안에 안 들어가는 단수, 5단 초과.

## 4.1 붙박이장 통 (2026-10-30 「칸마다 바꾸기」)

붙박이장 통은 위 석가 · 선반 배치를 쓰지 않는다 — 통 구조(`bom-wardrobe-rules.js`)의 칸마다 선반 수 `cellShelves` 와 내부 서랍(`drawers` · `externalDrawer: false`)으로 바꾼다
(wardrobe.md §1.3 「칸마다 선반 수」). 칸 간격 최소 300 은 붙박이장에 걸지 않는다 — [확인 필요].
붙박이장 **석가는 세로칸막이**다 (2026-10-30 사장님 — 칸을 좌우로 고르게 나누고 나뉜 칸마다 짧은 옷봉, `cellSplits` · wardrobe.md §1.3 「석가」). 위 §2 의 가로 석가가 아니다.
