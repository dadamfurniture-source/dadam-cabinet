# 싱크대 (Sink) 설계 규칙

> categoryId: `sink` / `island`

## 1. 기본 치수

| 항목 | 싱크대 | 아일랜드 |
|------|--------|---------|
| 기본 깊이 | 650mm | 800mm |
| 상부장 높이 | 720mm | - |
| 하부장 높이 | 870mm | 870mm |
| 상몰딩 높이 | 60mm | - |
| 다리발 높이 | 150mm | 150mm |
| 상부장 깊이 (BOM) | 295mm (고정) | - |
| 하부장 깊이 (BOM) | 550mm (고정) | - |

## 2. 레이아웃 형태

| 형태 | 설명 |
|------|------|
| I형 | 일자형 (기본) |
| L형 | ㄱ자형 (코너1 마감 필요) |
| U형 | ㄷ자형 (코너1 + 코너2 마감 필요) |

## 3. 워크스페이스 구조

- **상부장** (`pos: 'upper'`): 후드 위치 제외, 균등분배
- **하부장** (`pos: 'lower'`): 싱크볼, 쿡탑, 서랍장, 일반장, 키큰장(TL) 배치
- 상부/하부 각각 독립적 유효공간 관리

## 4. 모듈 타입

### 상부장
| 타입 | 설명 |
|------|------|
| storage | 일반 수납장 |
| hood | 후드 영역 (도어 없음) |

### 하부장
| 타입 | 설명 | 특수 속성 |
|------|------|-----------|
| storage | 일반 수납장 | isDrawer, isEL 토글 가능 |
| sink | 싱크볼장 | 기준 모듈 (isBase) |
| cook | 쿡탑장 | 기준 모듈 (isBase) |
| tall | 키큰장(TL) | doorCount, elCount 설정 |

### 모듈 속성
- `isFixed`: 고정 모듈 (자동계산 시 크기 유지)
- `isBase`: 기준 모듈 (싱크/쿡탑 — 자동배치 시 기준점)
- `isDrawer`: 서랍장 여부
- `isEL`: EL장(전동수납) 여부 — 활성화 시 너비 600mm로 고정 + isFixed

## 5. 키큰장(TL) 추가 규칙

```
기본 높이 = 전체높이(H) - 상몰딩(60) - 좌대(60)
기본 너비 = 600mm
기본 깊이 = 550mm
```

## 6. 자동계산 로직

싱크대는 `distributeModules()` 공통 알고리즘 사용 (→ common.md 참조)
- 상부장/하부장 각각 유효공간 기준으로 독립 분배
- 고정 모듈(isFixed) 제외 후 잔여공간을 비고정 모듈에 분배

### 하부장 · 서랍장 (2026-09-15, 정본 `js/detaildesign/bom-drawer-rules.js`)

`isDrawer` 모듈은 몸통(측판·지판·밴드·뒷판·처짐방지)은 위 표 그대로 내고, 전면·박스·목찬넬·레일은 아래 규칙으로 낸다.
도면: 아티팩트 "서랍장 목찬넬 구조 도면".

| 항목 | 규칙 |
|------|------|
| 전면 순서 (위→아래) | `doorCount>0` 이면 **도어 1칸 + 서랍 n단** (플래너 `doorTopDrawerBottom` 과 같은 그림), 아니면 서랍만. `drawerLayout:'all'` 로 강제 가능 |
| 서랍 단수 | `drawerCount` 1~4. 넘치면 4 로 자르고 경고 |
| 전면 높이 | `drawerFronts[i]` > (도어형이면) `drawerHeight`(기본 200) > 남는 높이 균등. 합은 항상 몸통 H: 상단 슬롯 30 + Σ전면 + 중간 슬롯 30×중간 목찬넬 수 + 갭 4×(목찬넬 없는 경계 수) |
| 목찬넬 수 | 전면과 1:1 이 아니다. 상단 1 (EP, 연속) + 중간 = "모든 전면이 슬롯 하나에 닿는 최소 수" — 아래에서 위로 짝짓기. 2단 1 · 3단 1 · 4단 2 |
| 중간 목찬넬 | 측판·칸막이 **90×40 따내기** = 전면판 72 + 지면판 18. 위 전면이 따내기 윗선보다 20 내려와 전면판 위 20 을 가리고, 그 아래 30 이 슬롯, 나머지 22 는 아래 전면 뒤. 한 슬롯에서 위 전면 밑단·아래 전면 윗단을 잡는다 |
| 존 (박스 자리) | 위 따내기 바닥(상단 70 / 중간 S+90) 또는 전면 경계 ~ 아래 따내기 윗선(S = 위 전면 밑 − 20) 또는 전면 경계, 마지막은 지판 윗면 (H−T) |
| 박스 높이 | 소 60 · 중 120 · 대 180 중 존에 **박스 + 레일 여유** 가 들어가는 가장 큰 것. 안 들어가면 소 + 비고 "레일 여유 부족" |
| 레일 여유 | 댐핑 언더레일(기본, `drawerRail:'under'`) 아래 30 · 위 10 = +40. 댐핑 볼레일(`'ball'`) 아래 10 · 위 10 = +20 |
| 레일 길이 | 규격 250·300·350·400·450·500 중 **모듈 깊이 − 50 이하의 최대** (D550 → 500, D450 → 400) |
| 박스 가로 | 앞뒷판 = W − 2×몸통T − 2×서랍T − (볼레일: 레일 두께 14×2 / 언더레일: 12). 서랍T = `drawerBoxT`(기본 몸통 T) |
| 박스 길이 | 측판 = 레일 길이 (언더레일은 −10) |
| 사쿠리 | `drawerSakuri` 면 앞뒷판 높이 = 측판 높이 − 18 |
| 우라(밑판) | 외경 (가로 − 1) × (측판 − 1). 사쿠리면 가로 = 앞뒷판 + 20, 세로 = 측판 − 1 |

| 부품 | 자재 | 두께 | 크기 | 수량 | 엣지 | 비고 |
|------|------|------|------|------|------|------|
| 도어 | MDF | 18T | (W/doorCount−4) × 도어 전면 H | doorCount | 4면 | 도어형만 |
| 서랍도어 | MDF | 18T | (W−4) × 서랍 전면 H | 단마다 1 | 4면 | |
| 서랍전후판 | PB | 서랍T | 박스 가로 × (박스H, 사쿠리면 −18) | 2 × 같은 박스 수 | 1면(장) | 비고 소/중/대 박스. 언더 15T·W800 → 728 |
| 서랍측판 | PB | 서랍T | 측판 길이 × 박스H | 2 × 같은 박스 수 | 1면(장) | 비고 레일 종류·길이. D550 언더 → 490, 볼 → 500 |
| 서랍밑판(우라) | MDF | 2.7T | 우라 가로 × (측판 − 1) | 단수 | - | W800 언더 15T → 757 × 489 |
| 서랍 하단보강 | PB | 서랍T | 측판 길이 × 60 | 단수 | 2면(장) | 앞뒷판 가로 > 600 |
| 목찬넬(중간 전면) | MDF | 18T | 72 × W | 중간 목찬넬 수 | 2면(장) | 비고 "중간 따내기 90×40" |
| 목찬넬(중간 지면) | MDF | 18T | 40 × W | 중간 목찬넬 수 | 2면(장) | |
| 측판 | | | | | | 비고 "목찬넬 따내기 상단 70×40 + 중간 90×40 ×k" (치수는 그대로 — 따냄은 가공) |
